# 城市无人机追逃仿真

一个使用 Vue 3、TypeScript、Three.js 和 Vite 的纯前端三维仿真。建筑、无人机模型和界面由浏览器绘制，运动、感知和追逃决策在 Web Worker 中运行，无需 Python 后端。

## 启动

**首次从 GitHub 下载或克隆后，需要先构建一次**，使用 Node.js 20.19+ 或 22.12+ 以及 pnpm，在项目目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm run build
```

**构建完成后，最省事的运行方式是双击项目目录里的 `启动仿真.cmd`。** 保留完整 `dist` 构建产物后，日常运行只需 Python 3.10+，无需 Node.js 或额外 Python 包；本机已用 Python 3.13 验证。

启动后会自动打开浏览器并进入 <http://127.0.0.1:8765/>。保持终端窗口开启，在终端按 `Ctrl+C` 可以停止服务。也可以手动运行：

```powershell
python run.py
```

`run.py` 只使用 Python 标准库提供本地静态文件服务，**不承担仿真计算**；三维渲染和仿真仍在浏览器内运行。如需修改端口或禁止自动打开浏览器：

```powershell
python run.py --port 8766 --no-browser
```

开发模式需要 Node.js 20.19+ 或 22.12+，以及 pnpm：

```powershell
pnpm install
pnpm dev
```

打开终端显示的开发地址。**修改 `src` 后，需要重新执行 `pnpm run build`，Python 启动入口才能提供更新后的页面。** `dist` 缺失时也需要先安装依赖并构建。生产构建与预览：

```powershell
pnpm run build
pnpm preview
```

## 页面操作

- 点击“开始仿真”，或使用空格键开始/暂停；暂停时可以单步推进 1/60 秒。
- 拖动旋转、滚轮缩放、右键平移。相机支持自由视角、俯视和跟随。
- 点击无人机或右侧编号，查看它的位置、速度、加速度和追踪目标。
- 选中蓝机可查看“任务巡航／临时规避／恢复任务”、任务目标坐标及已到达航点数；金色菱形标记的是任务目标，规避时会保留它。关闭“规划路径”也会隐藏任务标记。
- 红方数量可以设为 0，单独观察蓝方巡航。巡航没有终局，使用暂停或重置停止。
- 倍速支持 1×、2×、4×、8×。图层开关控制轨迹、规划路径和编号。
- 修改数量、性能、捕获半径或种子后，点击“应用参数并重置”；普通“重置”使用已经应用的参数。
- 种子旁的刷新按钮生成下一个种子的城市。同样种子、配置和仿真步数可复现相同状态。

## 仿真范围

- 按种子生成高低错落的城市建筑，并用简化四旋翼模型显示红蓝无人机。
- 默认 3 架红机与 6 架蓝机。红机最大速度 18 m/s、最大加速度 8 m/s²；蓝机分别为 12 m/s、5 m/s²。
- 红机根据观测选择并追逐蓝机，蓝机根据观测躲避红机；运动受建筑和飞行边界约束。
- 捕获半径默认 6 m，红蓝之间还必须没有建筑遮挡。捕获后蓝机退出运动，最后一架被捕获后仿真结束。
- 首版提供完全感知。这里的“打击”是接近捕获规则，不模拟武器、伤害、碰撞毁伤或实际飞控。

坐标单位为米，时间单位为秒。**仿真坐标采用 x、y 水平面，z 向上**，渲染层负责转换到 Three.js 的坐标约定。水平场景范围为 x/y ∈ [-300, 300]，高度上限为 150 m；红蓝双方统一保留 **12 m 水平边界缓冲**，机体中心限制在 x/y ∈ [-288, 288]、z ∈ [6, 148]。水平缓冲为边缘转弯和放大显示的模型留出空间，由 `HORIZONTAL_BOUNDARY_MARGIN` 定义，与建筑碰撞使用的 2 m 物理安全半径独立；它不改变捕获半径或建筑碰撞规则。

寻路、目标位置和制动走廊使用同一飞行边界。无人机通过加速度控制提前减速与转向，不会把飞行中的位置直接拉回边界内。

红方按观测进行目标分配与短时速度预测，使用三维栅格 A* 和直视路径简化。蓝方平时执行独立的航点巡航任务，近敌时临时规避，脱离威胁后恢复原任务。路径跟踪器使用加速度限幅与制动走廊检查，建筑碰撞采用膨胀包围盒的连续线段检查。

## 蓝方行为

蓝方使用任务巡航、临时规避、恢复任务三种状态。完全感知保持不变：知道红方的位置，不等于一直远离红方。

- **任务巡航**：每架蓝机拥有独立、可复现的随机序列，在城内可达航点之间移动。目标在到达或确实失效前保持稳定，无红方时同样执行任务。
- **临时规避**：最近红机进入 80 m 时触发规避，保留原任务点；在附近可达位置中综合短期安全、任务方向、转向连续性和边界代价。安全收益有上限，避免把“离红方越远越好”作为无限目标。
- **恢复任务**：最近红机远于 120 m 持续 2 s、且已规避至少 3 s 后，重新前往原任务；恢复 3 s 后回到巡航。进入／退出采用不同阈值和持续时间，减少状态抖动。

边缘软代价用于降低主动贴边倾向，12 m 硬缓冲继续负责实际飞行边界。当前使用参数与状态转换实现在 `src/sim/blue-policy.ts`；任务目标标记不等于无人机当前规避路线的终点。

## 运动模型

每架无人机维护三维位置 `position`、速度 `velocity`、加速度 `acceleration`。控制量是三个方向的**净加速度**，已包含悬停时的重力补偿；没有单独叠加重力，也不计算推力、电机转速或四旋翼姿态动力学。

固定仿真步长为 1/60 秒。未触发速度限制时，按常加速度积分：

```text
positionNext = position + velocity * dt + 0.5 * acceleration * dt²
velocityNext = velocity + acceleration * dt
```

最大速度和最大加速度限制的是三维向量长度，不是分别给三个轴相同上限。机体朝向、倾斜和旋翼动画用于显示，不参与质点动力学。

## 感知与后续扩展

`src/sim/types.ts` 定义统一契约：

```text
真实世界 SimulationSnapshot
  → SensorModel.observe(selfId, world)
  → Observation（自身、其他无人机、建筑）
  → 追逃策略与路径规划
  → 三轴净加速度
  → 运动更新
```

策略读取 `Observation`。仿真世界仍负责物理碰撞与捕获判定，因此物理规则不依赖某架无人机是否看见建筑。

`Simulation` 构造函数可以接受替换的感知模型：

```ts
const simulation = new Simulation(config, customSensor);
simulation.step();
const state = simulation.snapshot();
```

后续局部感知可在 `SensorModel` 中按距离、视场角、遮挡、延迟和噪声筛选观测。再接入视觉时，由机载相机图像经检测、定位和跟踪产生观测。机载相机图像渲染本身不等于视觉感知；当前版本不包含图像检测、深度估计或视觉建图。

## 测试与批量验收

```powershell
pnpm test
pnpm validate:sim
pnpm validate:sim --seeds=42,7,2026 --seconds=600
pnpm validate:bounds
pnpm validate:behavior
pnpm validate:behavior --output=output/mission-behavior.json
```

测试检查常加速度积分、向量限幅、线段穿楼、随机种子复现、快照隔离、蓝机确实移动、位置与速度合法、传感器替换、实际接近捕获和结束后状态冻结。

批量验收直接运行仿真核心，无需打开浏览器；默认使用种子 42、7、2026、1、99，每局最多运行 600 秒仿真时间。它按 60 Hz 积分、10 Hz 检查状态，输出每局捕获数、碰撞数、仿真用时和实际执行用时。未全部捕获、发生建筑碰撞或状态非法时退出码为 1。

2026-09-24 在默认配置下实测：21 项测试全部通过，包含边缘起点规划、边界附近连续制动、楼角路径跟踪、任务保持与恢复、威胁状态滞回、规划失败不虚增任务计数及无红方巡航。五个种子的完整局结果如下；表内时间是仿真时间，不是浏览器渲染耗时。

| 种子 | 捕获蓝机 | 运动碰撞拦截 | 全部捕获时间 |
| --- | --- | --- | --- |
| 42 | 6 / 6 | 0 | 67.43 s |
| 7 | 6 / 6 | 0 | 93.43 s |
| 2026 | 6 / 6 | 0 | 97.90 s |
| 1 | 6 / 6 | 0 | 78.70 s |
| 99 | 6 / 6 | 0 | 58.97 s |

默认种子 42 的每次捕获还逐帧核对了红蓝距离与建筑遮挡，确认是实际接近捕获。以上结果使用 12 m 水平边界缓冲；五个种子的每一步也检查了无人机中心和规划路径，均保持在 x/y ∈ [-288, 288] 内。以上覆盖当前地图生成器和默认参数，不代表任意配置均能成功。

`validate:behavior` 另外记录贴边时间、状态切换、航点完成数、街区覆盖和连续低位移时间。贴边定义为距地图侧边不足 40 m，以所有存活蓝机的累计时间为分母，按 10 Hz 采样；五个固定种子合并统计如下：

| 指标 | 原持续远离策略 | 当前任务巡航策略 |
| --- | --- | --- |
| 五个种子的贴边时间占比 | 66.09% | 0% |
| 无红方巡航 240 s 完成航点数（种子 42） | 0 | 54 |

当前无红方场景中，每架蓝机完成 8–10 个航点、覆盖至少 26 个街区格，最长连续低位移为 2.5 s；相同配置重复运行的最终状态一致。这里的低位移指每 0.1 s 位移不足 0.02 m。实际追逃中，种子 1 的 B06 在 26.75 s 进入规避、36.25 s 恢复任务、39.27 s 回到巡航，期间保留原目标。这是默认配置下的固定样本比较，不代表任意场景贴边率都为零。

验收报告 `output/baseline-behavior.json` 与 `output/mission-behavior.json` 是本地生成文件，不随仓库提交。当前策略的报告可通过上述 `pnpm validate:behavior --output=output/mission-behavior.json` 重新生成；原策略的数据为优化前的历史基线，当前源码不会生成原策略结果。

正式构建通过 `python run.py --no-browser` 提供服务。最终版本在浏览器跑完默认局：67.43 s 捕获 6/6，运动碰撞拦截为 0，无浏览器错误；任务点显示、暂停／单步、参数重置及无红方巡航计数也已验证。生产构建通过 TypeScript 检查；Three.js 所在主包约 627 KB（gzip 约 171 KB），构建会提示大包建议，不影响本地运行。

俯视使用正交相机，消除高空轨迹相对地面边框的透视偏移；自由视角中的三维线框标明 600×600×150 m 空域。路面和线框共用 `WORLD_BOUNDS`。右侧提供选中无人机的“距侧边界”，便于直接核对实际位置。

## 已知边界

- 红机具有更高速度和加速度，但这不构成任意参数、任意地图或未来任意逃逸策略下必胜的数学保证。
- 这是用于算法迭代的简化追逃环境，不代表真实四旋翼飞行性能；不包含风、通信丢包、载荷、电池、传感器噪声和地面效应。
- 当前建筑为轴对齐几何体；无人机安全体积使用简化半径，不能代替精细网格碰撞。
- 不模拟无人机之间的物理碰撞；红蓝接近按捕获规则处理，同阵营之间没有碰撞毁伤。
- 完全感知是当前已实现的观测形式。局部感知与视觉感知属于后续工作。
- 随机种子与固定步长用于复现实验。浏览器帧率属于渲染性能，应与仿真时间分开理解。
